- # IOException
  入出力に対するエラーを扱う関数
  なんやねんこれわけわからんこと言うなしばくぞ と思っていたが割と額面通りっぽくて、フォルダがない、容量が足りん、とかで記入できなかったときに自然発生(というより失敗したら結果がこうなる)するものっぽい だから保存の関数でエラーが出たときこのクラスの例外が発生し、それをcatchが受け取り、処理を始めるという感じ、のはず
  追記:今回主に起こるのがファイル保存というだけで、通信がうまくいかなかった、指定したファイルが読み込めなかったなどでも発生はする 
  こいつわけわからんかったわボケ
